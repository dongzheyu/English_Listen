# English Listen - 专业英语听写训练工具

厌倦了枯燥的英语听写训练？试试 **English Listen** —— 一款让你爱上英语学习的现代化听写工具！

## 项目概述

English Listen 是一款专为英语学习者设计的智能听写软件。它不仅仅是一个单词播放器，更是你提升听力和拼写技能的秘密武器。无论你是学生、教师还是自学爱好者，它都能帮你轻松搞定英语听写。

## 快速入门指南

### 图形界面版使用流程

1. **准备阶段**：在单词列表中添加你要练习的单词
2. **开始训练**：点击"开始听写测试"，软件会自动朗读单词
3. **听写记录**：在纸上写下听到的单词
4. **核对答案**：测试结束后可查看标准答案
5. **反复练习**：针对错误单词进行重点训练

### 快捷键操作

在听写测试界面中，您可以使用以下快捷键：

| 快捷键 | 功能描述 |
|--------|----------|
| 空格键 | 重复朗读当前单词 |
| 左方向键 | 返回上一个单词 |
| 右方向键 | 跳转到下一个单词 |
| ESC键 | 暂停/继续测试 |

#### 使用方法

1. 开始听写测试后，无需点击任何按钮
2. 使用键盘快捷键即可控制播放：
   - 按空格键重新听当前单词发音
   - 按左方向键返回上一个单词
   - 按右方向键跳到下一个单词
   - 按ESC键暂停或继续测试

#### 实现细节

快捷键功能通过重写[QMainWindow](file:///D:/msys64/mingw64/include/qt6/QtWidgets/qmainwindow.h#L58-L266)的[keyPressEvent](file:///D:/msys64/mingw64/include/qt6/QtWidgets/qwidget.h#L310-L310)函数实现。当前只在测试界面中启用了快捷键功能，以避免与其他界面的输入冲突。
