# English Listen - 你的专属英语听写助手 🎧

厌倦了枯燥的英语听写训练？试试 **English Listen** —— 一款让你爱上英语学习的现代化听写工具！

## 💡 什么是 English Listen？

English Listen 是一款专为英语学习者设计的智能听写软件。它不仅仅是一个单词播放器，更是你提升听力和拼写技能的秘密武器。无论你是学生、教师还是自学爱好者，它都能帮你轻松搞定英语听写。

## 🌈 核心特色一览

### 📚 智能词库管理
- 随心添加/删除单词
- 支持批量导入导出
- 多级文件夹分类管理
- 自动保存学习记录
- 实时保存到临时词库文件
- 支持词库"另存为"功能
- 编辑查看单词界面时自动创建临时词库，无需手动创建即可开始听写

### ⏱️ 个性化训练节奏
- 自由设定朗读间隔时间
- 暂停/继续功能随时掌控
- 上一词/下一词快速切换
- 重复播放强化记忆

### 🎨 舒适视觉体验
- 深色/浅色主题一键切换
- 自动适配 Windows 系统主题
- 动态欢迎界面增添趣味
- 响应式设计适配各种屏幕

### 📊 学习进度可视化
- 记录每次测试的成绩和时间
- 通过图表展示学习进度和趋势
- 支持准确率和正确数的可视化展示
- 历史记录自动保存和加载

### 🗣️ 高质量语音合成
- 集成 Windows SAPI 语音引擎
- 支持 Flite 第三方语音引擎
- 发音清晰自然，接近真人
- 支持各种标点符号和特殊字符
- 无需网络，离线也可使用
- 支持 Flite 引擎自动下载

### ✏️ 智能听写模式
- 纸笔听写模式：传统的听写练习方式
- 在线听写模式：先听写后统一提交答案，实时核对结果
- 用户可以边听边输入听到的单词，最后统一查看结果

## 🚀 快速上手指南

### 图形界面版使用流程：
1. **准备阶段**：在单词列表中添加你要练习的单词
2. **开始训练**：点击"开始听写测试"，软件会自动朗读单词
3. **听写记录**：在纸上写下听到的单词
4. **核对答案**：测试结束后可查看标准答案
5. **反复练习**：针对错误单词进行重点训练

- **跨平台兼容**：完美适配 Windows 系统
- **零依赖运行**：内置所有必需组件

## 📄 快捷键说明

在测试界面中，您可以使用以下快捷键：

- **空格键**：重复朗读当前单词
- **左方向键**：返回上一个单词
- **右方向键**：跳转到下一个单词
- **ESC键**：暂停/继续测试

更多详细信息请参见 [快捷键使用说明](SHORTCUTS.md)。
